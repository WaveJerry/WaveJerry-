OutDemo01_ - Pac-Man style console game for Dev-C++

Open OutDemo01_.dev in Dev-C++ and choose Compile & Run.
This version uses the Windows console and needs no graphics library.

Controls:
  Arrow keys or W/A/S/D : move
  P                    : pause/resume
  R                    : restart with a new maze
  Esc                  : quit

Eat all dots to win. Power dots let you eat ghosts for bonus points.
You have 3 lives. Each new game generates a connected maze.

The console should be at least 64 columns wide and 25 rows high.
