OutDemo02_吃豆人 - EasyX graphical Pac-Man style game

Open OutDemo02_吃豆人.dev in Dev-C++ and choose Compile & Run.
This version uses the EasyX graphics.h installed with your Dev-C++.

Controls:
  Arrow keys or W/A/S/D : move
  P                    : pause/resume
  R                    : restart with a new maze
  Esc                  : quit

Eat all dots to win. Power dots let you eat ghosts for bonus points.
You have 3 lives. Each new game generates a connected maze.

Project linker options:
  -leasyx -lgdi32 -lwinmm
