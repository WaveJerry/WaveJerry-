Pac-Man / Dev-C++ + EasyX
========================

打开 Pacman_EasyX.dev，然后按 F11 编译并运行。
也可以直接运行 Pacman_EasyX.exe。

操作：
  Enter       开始游戏 / 进入下一关 / 失败后重试
  方向键/WASD  移动
  P           暂停或继续
  R           从第一关重新开始
  Esc         退出

玩法：吃完迷宫里的全部豆子即可进入下一关。大能量豆使幽灵暂时变蓝，
此时可以吃掉幽灵得分。每局有 3 条命，过关后分数和剩余生命保留。

项目不依赖图片、音频等额外资源。已针对本机 D:\Dev-Cpp 中的
MinGW64 4.9.2 和 EasyX 编译。
